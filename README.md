## 👁️ Overview

**Flowy v1** transforms your everyday desktop into a sleek, futuristic, and highly responsive workspace. Designed with a focus on deep transparency, fluidity, and modern UI aesthetics, Flowy bridges the gap between functional desktop setups and Next-Gen visual design.

## 🚀 Installation & Setup

Follow these steps to apply Flowy v1 to your system:

### 1. Wallpaper Setup
* Download the latest wallpaper package from the [Releases page](../../releases/latest) (download `release##.zip`).
* Extract the archive and set your preferred wallpaper.

### 2. Taskbar & Explorer Modifications
1. Download and install **[Windhawk](https://windhawk.net/)**.
2. Open Windhawk, search for the **Taskbar Styler** mod, and click **Install**.
3. In the mod settings, select the **Liquid Glass Theme**.
4. Search for and install the **Win32 Modernizer** mod.
5. In the Win32 Modernizer configuration, **switch every toggle to ON**.

### 3. Zen Browser Setup
1. Open **[Zen Browser](https://zen-browser.app/)**.
2. Search for and install the **Sine** mod.
3. Install and apply the **Zia** theme.
